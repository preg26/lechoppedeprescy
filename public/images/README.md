# Images du site L'échoppe de Prescy

## Logo

Pour que le logo s'affiche correctement dans le header :

1. Placez votre fichier logo dans ce dossier : `public/images/logo.png`
2. Le logo doit être au format PNG avec fond transparent
3. Dimensions recommandées : 200px de hauteur (la largeur s'adaptera automatiquement)

Le logo fourni par l'utilisateur montre un poinçon de bijoutier avec le texte "L'échoppe de Prescy" en typographie élégante.

## Images de fond

Les images de fond des sections utilisent actuellement des photos professionnelles d'Unsplash :
- Hero : Bijoux et outils de bijouterie
- Savoir-faire : Mains d'artisan au travail
- Créations : Bijoux en gros plan
- Atelier : Établi de bijoutier avec outils
- Contact : Atelier de bijouterie

Ces images peuvent être remplacées par vos propres photos en modifiant les URLs dans `templates/main/home.html.twig`.
