# Instructions pour placer le logo

## 📸 Logo fourni

Vous avez fourni le logo officiel de L'échoppe de Prescy (poinçon de bijoutier avec typographie élégante).

## 📁 Où placer le logo

1. **Enregistrez l'image du logo** que vous avez fournie
2. **Placez-la dans** : `public/images/logo.png`
3. Le logo s'affichera automatiquement dans le header du site

## 🎨 Format recommandé

- **Format** : PNG avec fond transparent
- **Dimensions** : Environ 200-300px de hauteur (la largeur s'adaptera automatiquement)
- **Nom du fichier** : Exactement `logo.png`

## 🔄 Alternative : Upload via l'interface admin

Vous pouvez aussi uploader le logo via l'interface d'administration :

1. Connectez-vous à http://localhost:8000/admin/login
2. Allez dans **Logo** dans le menu
3. Cliquez sur "Choisir un fichier"
4. Sélectionnez votre logo
5. Cliquez sur "Mettre à jour le logo"

Le logo sera automatiquement enregistré dans `public/images/logo.png`.

---

## ✅ Vérification

Une fois le logo placé, rafraîchissez la page d'accueil pour le voir apparaître en haut à gauche du menu principal.
